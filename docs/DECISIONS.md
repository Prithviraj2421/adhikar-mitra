# Decisions

1. **Scheme catalogue (18).** Central: PM-KISAN, PM-JAY, PMAY-G, PMAY-U, PM Ujjwala, e-Shram, PM-SYM, Atal Pension, PMJJBY, NSAP IGNOAPS, PMMVY.
   Maharashtra: Sanjay Gandhi Niradhar Anudan, Shravanbal, MJPJAY, Majhi Ladki Bahin, Namo Shetkari, MahaDBT post-matric scholarship, BOCW registration.
   Dropped PM Suraksha Bima and PM Fasal Bima to keep coverage across pensions, health, housing, farmers, women, students and informal workers.
2. **Unverified by design.** Every scheme is `verified: false`; uncertain thresholds carry `note: "VERIFY"`. See `DATA_SOURCES.md`. The demo personas are tuned to these placeholder thresholds (for example the ₹50,000 income limit used for the Maharashtra pensions), so changing a threshold can change the demo.
3. **Household schemes counted once.** `target: HOUSEHOLD` schemes are evaluated against the head (SELF, else oldest member) so totals are not inflated.
4. **Estimated annual value.** One-time benefits (housing) are spread over 5 years; insurance uses a rough premium-equivalent. All are labelled "estimated".
5. **Runtime state.** Citizen and Sahayak state is kept in browser storage (localStorage + IndexedDB); Prisma/SQLite holds the schema, the seed data and the synced Sahayak households. The Benefit Gap Map is computed in the browser from the same deterministic generator that feeds the seed, so the map and the database agree.
6. **Own tiny i18n instead of `next-intl`.** Flat `messages/{en,hi,mr}.json`, locale from the URL segment, `t(key, vars)`. Fewer moving parts with the App Router and static params; a test fails if any key is missing in any language or if a placeholder differs. `next-intl` was removed.
7. **Tooling.** Vitest 3 + Vite 6 (Vitest 5 needed a Vite peer that npm did not install). Prisma pinned to 6. Dependencies installed with `--legacy-peer-deps`. TypeScript target ES2018.
8. **Demo clock.** Personas are evaluated as of 2026-11-20 (demo "today"); the time-travel slider changes `asOfDate`. New families use the real date.
9. **Demo assets.** SAMPLE-watermarked SVGs are generated by `npm run assets` into `public/demo-assets/` (so they can be served). OCR runs on a canvas copy; the language data is fetched once from the tesseract CDN, so the first OCR needs internet.
10. **Accessibility evidence.** Automated axe-core (WCAG 2.x A/AA) audit on the main screens in all three languages, run with Playwright, instead of a Lighthouse score. It passes with no serious or critical violations. Manual screen-reader testing is still recommended.
11. **Deliberate gaps (stated honestly).**
    - PDF upload for the Rejection Decoder is not supported (photos only); the UI says so.
    - The optional Bhashini voice adapter is **not built**; the `BHASHINI_ENABLED` flag in `.env.example` is reserved and currently unused.
    - Offline mode was verified with the in-app Offline toggle and a page reload; it has not been tested with the device network fully disabled on a real phone.
    - Application status is entered by the user; there is no government sync (by design).
    - Rohan's "child entered class X" event produces no new scheme because none of the 18 seeded schemes opens at those classes; the diff correctly reports "no new schemes".
12. **Git.** Work was committed locally then pushed to `https://github.com/Prithviraj2421/adhikar-mitra` (branch `main`).
